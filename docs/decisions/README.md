# Architecture Decision Index

Architecture decisions use a four-digit sequence and one of these states:

- `Proposed`: under discussion and not authoritative;
- `Accepted`: approved and authoritative;
- `Superseded`: replaced by a later ADR, with both directions linked;
- `Rejected`: evaluated but not selected.

Accepted ADRs are historical records. Clarifications belong in the canonical
architecture document. Changing an accepted decision requires a new ADR.

# EF70 committed current-selection recovery

This bounded TEST Host executes one published managed controller restore against
the actual final Extension Foundation PR #70 push commit F. It accepts the genuine
successful H2 canonical-adoption artifact, preserves its original preparation P,
and records a new owner-produced current selection in a fresh disposable checkout.
It adds no production recovery mechanism or generic artifact framework.

## Inputs and execution

The reusable workflow is `.github/workflows/ef70-committed-recovery.yml`.
Its producer preflight branch is `test/ef70-committed-recovery`.
The preflight preserves all eight existing H2 source checks and adds the focused
recovery admission/intake tests. Ordinary required strict compilation includes
every new TypeScript source and test. Source feedback is not consumer admission.

## Original P and the new current selection

Published M reads the selected external `--preparation` path and checks
its exact digest. In its committed route, `initialProofPath` and the original
root/device/inode/birthtime remain unchanged historical fields. M derives the new
real root identity and verifies C's original tree/intent and C ancestry of F.
This fixture never rewrites P, creates an alias to the old root, or describes the
original root-bound forward preparation as transferable.

Before invoking restore, every managed F file must equal P's original postimage.
A Host/P7 overlap fails closed and requires an ordinary owner correction first.
The actual first restore uses:

```text
Node24 external-controller/dist/cli.js restore
  --consumer ACTUAL_F_ROOT
  --from ORIGINAL_TARGET --to docs-2026-10-03-stable31
  --source-generation 3 --target-generation 2
  --preparation UNCHANGED_EXTERNAL_P --expect ACTUAL_P_SHA256
  --current-revision ACTUAL_F --current-tree ACTUAL_F_TREE
  --selection FRESH_EXTERNAL_SELECTION --json
```

That call both creates the current selection and performs the inverse. There is
no read-only selection command and no automatic retry. An existing selection
requires the separate published selection-digest procedure; this first-call
fixture deliberately does not resume an uncertain attempt.

The result must independently report consumer.restore/restored, an applied
kernel receipt, the exact inverse plan, the new actual root/F/tree/inventory,
original builds and original P digest. Every managed file must match original C;
every independent file must match F, including the final validation caller.
Installed source package census, lock and manifests must match the genuine fresh
offline C fixture. HEAD/tree remain F. Original P/completion/receipt bytes remain
unchanged. Actual PID/start, closed streams, source images, public idle state and
retained runtime debt are captured. Unknown custody stops without retry,
rollback, guard removal, backup deletion or a full-host process-tree claim.

## Final caller and result boundary

The EF caller stays in the existing PR70 workflow file and selects the immutable
H3 source. Its commit is part of actual F. Triggering on real pushes to that
branch allows a genuine final correction to select a new F and a new current
selection. Do not remove or alter the caller after qualification and reuse the
old F proof. No second EF product PR or artificial empty trigger commit is needed.

`committed-recovery-complete.json` denotes only the observed disposable inverse.
The retained inverse patch must never be applied to the product branch. The
original artifact, actual raw command/error streams, new selection, full before
and after images, exported inverse bytes and real Git diff are retained on the
official Actions artifact route. Failure evidence is retained without a completion
claim. The unchanged reporter's historical campaign-completion flag remains false.

This does not qualify post-squash main ancestry, final native/trusted gates,
archive/LMU identity, observed binding, CANARY or merge. Those results remain
separate and must bind the actual final caller-inclusive PR head or merged main.
This producer test branch is not intended to merge.
